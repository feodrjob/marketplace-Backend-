# DAO слоя Catalog

В `mapper` преобразуем JPA-сущности в доменные модели.
В `repositoryImpl` реализуем интерфейсы из `domain/repository`.
JPA-адаптеры читают данные и загружают изображения внутри read-only транзакции.
Отбор доступных категорий и товаров остаётся в доменном сервисе.

`SellerShopLookupImpl` получает публичный магазин из Auth по HTTP.
Он возвращает `null` только при HTTP 404. Ошибка соединения, таймаут или
некорректный ответ Auth становятся `SellerShopUnavailableException`.
