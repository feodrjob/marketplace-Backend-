# Domain слой модуля catalog
В `model` хранятся доменные модели и команды каталога (например, `ProductModel`, фильтры и команды обновления).
В `service` лежит бизнес-логика каталога и поиска товаров.
В `repository` лежат доменные интерфейсы доступа к данным.
В `mapper` лежат доменные мапперы.
Domain не зависит от web, infrastructure и config.
