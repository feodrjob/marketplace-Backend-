Здесь настраиваем Spring. В SecurityConfig задаём правила доступа к маршрутам и подключаем фильтр из web/security. Здесь же объявляем бины, например PasswordEncoder, который получает сервис аутентификации.

Config знает компоненты других слоёв, которые нужно настроить или связать. Остальные слои не импортируют config. Сценарии регистрации и входа находятся в domain/service.
