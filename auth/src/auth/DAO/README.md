Здесь соединяем доменные репозитории с базой. В repositoryImpl лежат реализации интерфейсов из domain/repository. Они вызывают Spring Data-репозитории из infrastructure/persistence/repository. Мапперы из mapper преобразуют JPA-сущности в доменные модели и обратно.

DAO знает интерфейсы и модели domain, а также сущности и репозитории из infrastructure. Он не зависит от web и config. Доменные сервисы получают интерфейс репозитория через конструктор, поэтому могут работать с другой реализацией без изменения сценария.
