В controller лежат HTTP-эндпоинты, в dto — данные запросов и ответов, в mapper — преобразования между DTO и моделями или командами из domain. Например, маппер преобразует SignInRequest в SignInCommand, а контроллер вызывает AuthenticationService и оформляет HTTP-ответ. В security лежит JWT-фильтр входящих запросов.

Web обращается к публичным методам domain/service и использует модели и команды из их сигнатур. Он может использовать общие типы из common. Контроллеры не обращаются к domain/repository, DAO и infrastructure. Проверки учётных данных и правила работы с профилем выполняют сервисы.
