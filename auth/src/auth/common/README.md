Здесь лежат типы, общие для нескольких слоёв Auth. Например, enums/Role задаёт роли пользователей, которые используются в доменной модели, при сохранении в БД и при формировании ответа API.

Другие слои могут использовать common. Сам common не зависит от них. Типы, которые нужны только контроллеру, одному сервису или БД, лежат рядом с этим кодом.
