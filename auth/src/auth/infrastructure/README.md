В persistence/entity лежат JPA-сущности, которые описывают таблицы. В persistence/repository лежат интерфейсы Spring Data, которые читают и сохраняют эти сущности. Например, UserRepository работает с JPA-сущностью пользователя, а его вызывает адаптер из DAO/repositoryImpl.

Persistence знает свои сущности, Spring Data и общие типы из common, если они нужны для хранения данных. Он не зависит от web, config, DAO и доменных сервисов. Преобразование между сущностью БД и доменной моделью находится в DAO/mapper.
